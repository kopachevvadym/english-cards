## Інтерфейс користувача
- Головна сторінка з оглядом прогресу користувача
- Сторінка зі списком слів для вивчення
  - Тут будуть теми та категорії слів
- Чат для спілкування з ботом
- Тренування з інтерактивними вправами
  - Тут будуть різні методи вивчення слів

## Види інтерактиву для вивчення іноземної мови
- вибір перекладу слова зі списку варіантів
- аудіювання з вибором правильної відповіді
- тренування словникового запасу через флеш-карти
- тренування граматики через переміщення слів у реченні, щоб утворити правильний порядок

- вибір правильної відповіді по опису зі списку варіантів слів
- скласти правильно речення з наданих слів
    - тренування граматики через вправи на заповнення пропусків
- аудіо опис слова яке потрібно обрати
- вставити пропущені слова в речення
- складення слова з складів
- тренування розмовної мови через діалоги з ботом

## Фічі
- Черги для повторення слів на основі інтервального повторення
  - кожна спроба вивчення слова впливає на інтервал до наступного повторення 
  - кожна спроба зберігається в історії користувача 
- Спілкування через чат для практики мови 
- MCP сервер для керування словником і прогресом користувача 
  - Можна створовати тематичні списки слів 
- Повторення слів на основі речень
- Є тематичні категорії слів та речень та висловів
- Спілкування з ботом для практики мови через чат, але він розмовляє від імені якоїсь ролі
- Щоб побачити переклад слова чи речення, потрібно перевернути телефон
- Зробити адаптивний дизайн для мобільних пристроїв
- Можливість генерувати власні тематичні списки слів і висловів
- Проходження занять напряму через чат з ботом 
  - Там можна буде попросити створити заняття і прямо в чаті буде кнопка щоб почати заняття
- Можливість імпортувати словники з інших сервісів

Функція спілкування через чат і щоб через mcp сервер можна було:
    додавати слова у словник,
    створювати речення для тренування,
    додавати прогрес по вивченню слів
    додавати слова в черги для повторення

Властивості слів:
    слово
    переклад
    приклади використання
    рівень складності
    категорії (наприклад, їжа, подорожі, робота)
    дата додавання
    кількість повторень
    остання дата повторення
    користувач, щоб можна було користуватися багатьма користувачами

Властивості тематичних категорій:
    назва категорії
    опис категорії
    список слів у категорії

Властивості особи користувача:
    ім'я користувача
    електронна пошта
    рідна мова
    мова яку вивчає
    рівень володіння мовою
    історія тренувань (дати, результати)

Технічні вимоги
    Збереження даних у MongoDB
